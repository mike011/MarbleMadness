Marble Madness

Watch both solutions build marble sequences

Everything here uses 4 colours: blue, green, red and yellow. There are 136 valid sequences. Your Java version made 130 of them. Step through the animations to see which 6 it missed and why.

First, why are colours added together?

The machine makes marbles, and the README says a marble can be made of one colour or two colours mixed together. So the colours aren't really being added. Some marbles are simply made of two colours. In the output, a + joins the colours inside one marble, and a space separates one marble from the next. Each colour can be used at most once per sequence, so a two-colour marble uses up both of its colours.

blue1 marble, made of blue.
blue+green1 marble, made of blue and green together.
blue green2 marbles: a blue one, then a green one.
blue+green red2 marbles: a blue-and-green one, then a red one.
blue+green red+yellow2 marbles, both two-colour. Your version never makes this kind.

Two rules that are easy to mix up

Inside a marble, order doesn't matter. blue+green and green+blue are the same marble, so only one is listed.

Between marbles, order does matter. blue green and green blue are different sequences, because the marbles come out in a different order.

The README's sample shows both rules. Input 2 gives exactly 5 sequences, with blue+green but no green+blue:

blue green blue+green blue green green blue

Why two-colour marbles make the problem harder

Choosing the colours and their order isn't enough. You also have to decide how the colours are grouped into marbles. Using all four colours, there are three ways to group them:

4 single-colour marbles 24 sequences Your version makes these
1 two-colour marble + 2 singles 36 sequences Your version makes these
2 two-colour marbles 6 sequences Your version misses all 6

Your version puts the colours in every order, then glues one neighbouring pair into a two-colour marble. That covers the first two groupings but never the third, because the third needs two pairs glued in the same sequence. The animations below show this step by step.

Your version
  1. Line the colours up in every order.
  2. Take one ordering and glue one neighbouring pair into a two-colour marble.
  3. Put the pair back, glue the next pair, and repeat.

It never glues two pairs in the same sequence, so blue+green red+yellow is never made.

Correct version
  1. Start with an empty sequence.
  2. For the next position, choose any unused colour, or any unused pair.
  3. Keep going until the sequence is full, then back up and try the next choice.

Every position can hold a pair, so sequences with two pairs come out naturally.

1. Your version: line up, then glue one pair

Your code goes through all 24 orderings of the four colours. For each one it glues positions 1+2, then 2+3, then 3+4, starting again from the plain ordering every time. If the same pair in the other order was already made, it skips that one.

2. Correct version: fill the sequence one marble at a time

The machine does one pass for each sequence length: 1 marble, then 2, 3 and 4. At each position it tries every unused single colour, then every unused pair. When the sequence is full it records it, then takes the last marble back out and tries the next choice. That step is called backtracking.
